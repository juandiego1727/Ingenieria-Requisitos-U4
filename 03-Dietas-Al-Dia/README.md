# Dietas al Día

## Descripción

Prototipo funcional de alta fidelidad para la aplicación Dietas al Día.

El sistema está orientado a médicos nutricionistas y permite consultar la información clínica de los pacientes, identificar dietas compatibles y realizar la asignación de un tratamiento nutricional.

## Artefactos

- PROTOTIPADO.pdf
- Prototipo funcional en Figma

## Requisitos relacionados

- RF01: El sistema muestra las dietas asociadas con la enfermedad registrada.
- RF02: El sistema identifica alergias e incompatibilidades antes de confirmar la asignación.
- RF03: El sistema permite consultar la ficha técnica de la dieta sin perder el contexto del paciente.
- RF04: El sistema permite seleccionar y asignar una dieta segura.
