# Código complementario – Dietas al Día

Este código fue elaborado específicamente para la Actividad 1 de Trazabilidad
como artefacto complementario. No corresponde a un repositorio original del
proyecto.

## Tecnologías
- React
- Vite
- CSS

## Flujo implementado
Inicio de sesión → Mis pacientes → Historia clínica → Dietas compatibles →
Ficha técnica → Confirmación → Asignación completada.

## Trazabilidad
- RF01: muestra dietas asociadas al diagnóstico.
- RF02: muestra alerta de incompatibilidad por alergia al maní.
- RF03: permite consultar la ficha técnica manteniendo el contexto del paciente.
- RF04: permite seleccionar una dieta compatible dentro del flujo.

## Ejecución
1. Instalar Node.js.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.
